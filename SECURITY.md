# Security policy

This repository publishes research code, benchmark orchestration, and bounded
evidence; it is not a supported production distribution.

Please report a suspected credential leak, unsafe benchmark command, or
memory-safety issue through a private GitHub security advisory for this
repository. Do not include credentials, private host names, GPU UUIDs, process
identifiers, or private filesystem paths in a public issue.

The public evidence verifier intentionally rejects known private-environment
fields and raw binary/codegen artifacts.
