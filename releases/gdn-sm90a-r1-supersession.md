# Report release r1 supersession

`gdn-sm90a-r1` remains a public, immutable audit record. Its runtime source,
historical and fresh evidence seals, source identities, performance values,
tag CI, and downloaded asset hashes remain valid.

The release is superseded for new platform publication because its
publication checklist, publishing order, correction template, architecture
figure, and chart map retained obsolete pre-rerun state guidance. The same r1
package also contains the completed, separately sealed 66-receipt H20
`CHARACTERIZATION`, so those instructions were internally inconsistent.

The exact release, asset hashes, affected paths, validity boundary, and
no-mutation policy are recorded in
[`gdn-sm90a-r1-supersession.json`](gdn-sm90a-r1-supersession.json).

Use `gdn-sm90a-r2` for any new X, Zhihu, WeChat, or other downstream
publication. The r2 correction does not change runtime code, either evidence
bundle, any latency or ratio, or any source coordinate.
